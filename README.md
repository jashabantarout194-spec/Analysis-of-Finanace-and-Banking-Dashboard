# Analysis-of-Finanace-and-Banking-Dashbord 

🧰 Tools Required
Power BI Desktop – main tool to build dashboard

Data source – Excel / CSV / Database (finance dataset)

Basic knowledge of:

Data (revenue, loans, customers, etc.)

Charts & visualization

📊 Step-by-Step Process
1️⃣ Collect Data
Prepare a dataset with finance/banking details like:

Customer Name

Account Type

Loan Amount

Revenue / Profit

Date (monthly/yearly)

Branch / Region

👉 Usually stored in Excel (.xlsx) or CSV file

2️⃣ Load Data into Power BI
Open Power BI

Click Home → Get Data

Choose Excel/CSV

Load your dataset

3️⃣ Clean & Transform Data
Open Power Query Editor

Remove duplicates

Fix missing values

Change data types (date, number, text)

Click Close & Apply

👉 This ensures your data is accurate

4️⃣ Create Visualizations (Charts)
Now add different charts based on analysis:

📊 Bar Chart
Select Bar Chart visual

Drag:

Axis → Category (e.g., Branch)

Values → Loan Amount / Revenue

🟠 Pie Chart
Select Pie Chart

Show distribution (e.g., Expense types)

🍩 Donut Chart
Similar to pie

Add total profit in center

📈 Line Chart
Axis → Date

Values → Revenue / Transactions
👉 Shows trends over time

🎀 Ribbon Chart
Axis → Time (Month)

Legend → Category (Branch/Product)
👉 Shows ranking changes

🔻 Funnel Chart
Values → Number of customers

Group → Loan stages
👉 Shows drop from application → approval

5️⃣ Format Dashboard
Go to Format pane

Add:

Titles

Colors

Background image

Adjust transparency and layout

6️⃣ Add Filters (Slicers)
Add Slicer visual

Filter by:

Date

Region

Account type
👉 Makes dashboard interactive

7️⃣ Create Relationships (if multiple tables)
Go to Model view

Connect tables using common fields (e.g., Customer ID)

8️⃣ Publish Dashboard
Click Publish

Upload to Power BI Service

Share with others
